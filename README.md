## 📌 Tentang Repository

Repository ini merupakan tempat penyimpanan seluruh dokumentasi, source code, dan hasil pengerjaan tugas kelompok pada mata kuliah **Pemrograman Web (PWD)**.

Repository dikelola secara kolaboratif menggunakan Git dan GitHub untuk memudahkan pengembangan, dokumentasi, pembagian tugas, serta pengumpulan hasil pekerjaan setiap anggota kelompok.

## 🎯 Tujuan Repository

- Mendokumentasikan setiap tugas dan praktikum Pemrograman Web.
- Menyimpan source code dan file pendukung secara terstruktur.
- Memudahkan anggota kelompok dalam berbagi dan memperbarui pekerjaan.
- Menerapkan penggunaan Git dan GitHub dalam kolaborasi pengembangan web.
- Menjadi arsip perkembangan pengerjaan tugas selama perkuliahan.

## 🚀 Panduan Menggunakan Repository

### 1. Clone Repository

Jalankan perintah berikut pada terminal:

```bash
git clone git@github.com:Sakiih/PWD_TEORI_KELOMPOK.git
```

### 2. Masuk ke Folder Repository

```bash
cd PWD_TEORI_KELOMPOK
```

### 3. Perbarui Repository

Sebelum mulai mengerjakan tugas, ambil perubahan terbaru:

```bash
git pull origin main
```

### 4. Mulai Mengerjakan

Buka folder tugas yang ingin dikerjakan menggunakan editor kode.

### 5. Simpan dan Kirim Perubahan

Setelah melakukan perubahan, jalankan:

```bash
git add .
git commit -m "Deskripsi perubahan"
git push origin main
```

**Catatan:** Pastikan perubahan anggota lain sudah diambil sebelum melakukan push agar mengurangi risiko konflik.

## 🤝 Kolaborasi Kelompok

Seluruh anggota kelompok diharapkan menjaga konsistensi dan kerapian repository dengan mengikuti beberapa ketentuan:

1. Gunakan nama file dan folder yang jelas.
2. Pisahkan setiap tugas berdasarkan folder masing-masing.
3. Berikan pesan commit yang menggambarkan perubahan.
4. Lakukan `git pull` sebelum memulai pekerjaan.
5. Hindari mengunggah file yang tidak diperlukan.
6. Pastikan setiap tugas memiliki dokumentasi yang memadai.
